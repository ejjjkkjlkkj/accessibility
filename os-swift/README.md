# os-swift

Sources Swift du projet « operating system » : applications (core, desktop, agent, explorer, shell, intent, native, recovery), moteur (`engine/`), tests (`coretests/`, `settingstests/`, `tests/`), sources partagées (`src/`), interface web (`web/`), et spécifications (`docs/`).

Les binaires compilés, les journaux, les poids de modèle et les fichiers volumineux ne sont pas inclus.
