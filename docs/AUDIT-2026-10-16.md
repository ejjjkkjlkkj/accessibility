2. **CI validation gaps — corrected in workflow configuration.** Added explicit JSON parsing for the language manifest and NEXORA contract; hardened relative-link handling; removed whole-repository Python bytecode compilation in favor of compiling tracked Python source files only; added a Go formatting gate.
3. **Go validator hardening — corrected.** The validator now rejects malformed DNS labels, missing/invalid URL hosts, URL userinfo, unsupported schemes, and host/domain mismatches. Regression tests cover malformed URLs, invalid domain syntax, duplicate IDs/headers, empty input, missing fields and subdomains.
4. **Go formatting — corrected.** The CI failure identified unformatted role and screen-reader cursor sources/tests. These files were formatted, cursor state assertions were added, and the CI formatter invocation was hardened for tracked paths.
5. **Repository hygiene across branches — corrected.** Added a root `.gitignore` to all 12 branches. Removed 31 tracked Rust `target/` and Python cache/bytecode artifacts from `agent/own-model-development`. Added a CI guard against tracked build/cache output on the main validation workflow.
6. **Automation publication controls — hardened.** The resource-database workflow now uploads generated outputs as artifacts and never pushes directly to `main`. The hourly audit now fails if discovered Rust tests fail. The repository-owned model workflow is manual, self-hosted, read-only, and does not publish automatically on `main` or feature branches.
7. **Local model loop — hardened.** On `feature/haker-reproducible-security-gates-20261015`, the hosted Codex/API-key workflow was replaced with a manual self-hosted Ollama workflow. Auto-push is now disabled by default in the local agent, supervisor, and two-repository installer; regression tests cover the default and explicit opt-in.
8. **Semantic tree validation — hardened across 11 branches with this Rust core.** Added a 512-node cap, 64-link ancestry-depth cap, 4096-byte UTF-8 name cap, embedded-NUL rejection, unknown/contradictory state-flag rejection, and a single-focused-node invariant, with regression tests and updated documentation.
9. **No unapproved release action.** No branch was deleted, no pull request was merged, and no firmware write, NVRAM modification, or physical reboot was performed.
